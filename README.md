# Evaluación final: Herramientas de IA Clásica

## Guillermo Parés Marín

Proyecto de la evaluación final de la asignatura **Herramientas de IA Clásica**, del Máster en Inteligencia Artificial, Cloud Computing y DevOps (PontIA).

Es un asistente conversacional por voz construido con Dialogflow ES, un webhook en FastAPI y OCR sobre documentos.
